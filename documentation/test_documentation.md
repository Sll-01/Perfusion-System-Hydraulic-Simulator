# Test documentation

The automated test-suite (`pytest`, folder `tests/`) is run with `run_tests.bat` (Windows) or `python -m pytest`.
Current results: see `test_results.md` (generated by `tools/generate_test_report.py`) and the analytical reference cases
in `verification_report.md` (generated by `tools/generate_verification_report.py`).

## Numerical tolerances

| Quantity | Tolerance | Rationale |
|---|---|---|
| analytical laminar relations (HP, Darcy, R~L, R~d^-4, shear) | relative 1e-10 ... 1e-12 | exact up to floating point |
| network solutions (series/parallel, flow split, pump modes) | relative 1e-8 ... 1e-9 | solver tolerance: mass residual <= 1e-10 Q_s, pressure residual <= 1e-6 Pa |
| mass balance Q_pump = sum(Q_paths) | relative 1e-9 | conservation enforced at every node |
| empirical correlations (Blasius vs. Colebrook, water properties) | 0.01 % ... 3 % | correlations, not exact laws |
| sensitivities (elasticity -4 / +1) | 1 % | finite differences, residual minor losses |
| optimisation (homogeneous distribution) | CV < 0.5 % | iterative derivative-free optimiser |
| calibration recovery | relative 1e-3 | least-squares with synthetic data |

## Physical relations explicitly verified (spec. chapter 23)

* identical parallel paths -> identical distribution (V17, `test_symmetric_distribution`)
* higher resistance of one path -> less flow in that path, more elsewhere, higher pump pressure in mode A (`test_increasing_path_resistance_redistributes_flow`)
* laminar R ~ L and R ~ d^-4 (V02, V03, elasticity test)
* blocked path -> Q = 0 exactly (V16, `test_blocked_reactor_zero_flow`, `test_closed_throttle_zero_flow`)
* Q_total = sum of partial flows (V14, `_assert_mass_balance` in all network tests)
* pressure drop of passive paths non-negative in flow direction (`test_pressure_drop_non_negative_in_flow_direction`)
